# Linux Server Infrastructure

## Overview

This section documents the deployment, configuration, administration, and security of Linux servers within the simulated enterprise environment.

## Objectives

- Deploy Ubuntu Server.
- Configure hostname and static IP addressing.
- Configure SSH remote administration.
- Manage Linux users and groups.
- Configure file permissions.
- Implement server services.
- Configure system updates and security.
- Monitor system logs.
- Integrate Linux endpoints with Wazuh SIEM.
