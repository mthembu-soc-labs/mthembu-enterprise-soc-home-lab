# Windows Server & Active Directory

## Overview

This section documents the deployment and administration of a Windows Server 2022 environment for a simulated medium-sized company.

## Objectives

- Configure Windows Server 2022.
- Configure the server hostname and static IP.
- Install Active Directory Domain Services.
- Promote DC01 to a Domain Controller.
- Configure DNS.
- Create Organizational Units (OUs).
- Create and manage employee accounts.
- Configure security groups and Group Policy.
- Join employee workstations to the domain.
