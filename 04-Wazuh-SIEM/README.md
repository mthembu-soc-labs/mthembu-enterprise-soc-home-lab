# Wazuh SIEM Deployment and Configuration

## Overview

This section documents the deployment, configuration, and administration of Wazuh as the centralized Security Information and Event Management (SIEM) platform for the simulated enterprise environment.

## Objectives

- Deploy Wazuh Manager.
- Configure Wazuh Indexer and Dashboard.
- Access and manage the Wazuh dashboard.
- Deploy Wazuh agents.
- Integrate Windows endpoints.
- Integrate Linux endpoints.
- Monitor endpoint activity.
- Configure security detection rules.
- Investigate generated security alerts.
