# Incident Response

## Overview

This section documents practical cybersecurity incident response exercises conducted within the simulated enterprise environment.

The objective is to develop skills in identifying, analyzing, containing, and documenting security incidents.

## Objectives

- Understand the incident response lifecycle.
- Investigate suspicious authentication activity.
- Analyze brute-force attack attempts.
- Investigate compromised test accounts.
- Identify suspicious endpoint activity.
- Analyze Wazuh security alerts.
- Document investigation findings.
- Recommend appropriate remediation measures.

## Incident Response Lifecycle

1. Preparation
2. Identification
3. Analysis
4. Containment
5. Eradication
6. Recovery
7. Lessons Learned

## Planned Investigation Scenarios

- [ ] Multiple failed login attempts
- [ ] Brute-force authentication simulation
- [ ] Unauthorized login attempt
- [ ] Suspicious account activity
- [ ] Privilege escalation investigation
- [ ] Suspicious process execution
- [ ] Endpoint security alert investigation

## Incident Reports

Each completed investigation will include:

- Incident description
- Date and time
- Affected system
- Detection source
- Evidence collected
- Investigation findings
- Severity assessment
- Containment actions
- Remediation recommendations
- Lessons learned

## Evidence

Screenshots, event logs, Wazuh alerts, and investigation reports will be maintained as supporting evidence.

All testing will be conducted in authorized lab environments.
