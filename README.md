# Enterprise SOC Home Lab

## Project Overview

This project documents the design, implementation, configuration, testing, and security monitoring of a simulated medium-sized enterprise IT infrastructure.

The objective is to develop practical skills in IT infrastructure management, cybersecurity operations, Security Information and Event Management (SIEM), threat detection, and incident response.

## Project Objectives

- Build and manage a simulated enterprise network.
- Deploy Windows Server and Active Directory Domain Services.
- Configure Linux server infrastructure.
- Implement centralized security monitoring using Wazuh SIEM.
- Monitor Windows and Linux endpoints.
- Simulate and investigate security events.
- Document configurations, troubleshooting, and testing procedures.
