# Screenshots and Technical Evidence

## Overview

This directory contains visual evidence of the implementation, configuration, and testing of the enterprise SOC home lab.

## Evidence Categories

- Network topology and VLAN configurations
- Windows Server configuration
- Active Directory administration
- Linux server configuration
- Wazuh dashboard and agent status
- Security alerts and event logs
- Kali Linux security testing
- Connectivity and validation tests

## Evidence Guidelines

- Include a short description for every screenshot.
- Capture relevant configuration or test output.
- Use descriptive filenames.
- Include dates where useful.
- Remove passwords, API keys, tokens, and other sensitive information before publishing.

## Evidence Status

Screenshots will be added as each implementation milestone is completed and verified.
